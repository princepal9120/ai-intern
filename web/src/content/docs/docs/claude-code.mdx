## Container Isolation Architecture

Coding agents execute arbitrary terminal commands, run build tools, and install npm/pip packages. Running these tasks on production servers or developer workstations presents severe security risks.

AI Intern eliminates these risks using Cloudflare Sandbox:

- **gVisor Virtualization**: Each container executes in an isolated sandbox with kernel-level syscall interception.
- **Ephemeral Lifecycle**: The container filesystem is created on demand for a single task and destroyed upon completion.
- **Egress Filtering**: Outbound network connections are strictly restricted to approved package registries and GitHub.
- **AI Gateway Forwarding**: LLM API calls route through Cloudflare AI Gateway, keeping credentials off the container filesystem.

## Harness Selection

You can specify the execution harness on a per-task basis in your request payload:

```json
{
  "repoUrl": "https://github.com/princepal9120/ai-intern",
  "task": "Migrate tests to Vitest 5.0",
  "harness": "claude-code",
  "baseBranch": "main"
}
```

If omitted, AI Intern defaults to `opencode` for low-latency tasks and `claude-code` for complex refactors.
